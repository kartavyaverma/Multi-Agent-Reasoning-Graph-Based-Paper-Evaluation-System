# Chemistry sample test (PDF)

Chemistry IA 1: 10 questions × 5 marks = 50. Every question asks for a labelled diagram, and every script draws one
(Bohr model, Lewis structure, IE graph, Daniell cell, energy profile, distillation apparatus, titration curve,
benzene structures, Boyle's law graph, electrolysis cell). Scripts are handwriting-style on ruled paper.

| File | What it is |
|---|---|
| `question_paper.pdf` | Question paper (typed, 1 page) |
| `model_answer.pdf` | Model answer with reference diagrams and mark splits |
| `student_01_ishaan.pdf` … `student_04_sneha.pdf` | One script per student, 3-5 pages each |

Regenerate with `node scripts/make-chemistry-samples.js` from `server/` (needs the Windows fonts Arial, Ink Free, Segoe Print).
