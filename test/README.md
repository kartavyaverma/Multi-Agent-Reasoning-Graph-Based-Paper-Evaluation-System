# Sample test papers (PDF)

Engineering Physics IA 1: 4 questions × 5 marks = 20. The student scripts are written in handwriting-style fonts on ruled paper and include drawn V-I graphs.

| File | What it is |
|---|---|
| `question_paper.pdf` | Question paper (typed) |
| `model_answer.pdf` | Model answer and marking scheme with mark splits and a reference graph |
| `student_01_aarav.pdf` … `student_06_meera.pdf` | One script per student, 2 pages each |
| `combined_all_students.pdf` | All 6 scripts in one PDF (12 pages) |

## How to test
**One PDF per student:** on **New test**, upload `question_paper.pdf` and `model_answer.pdf`. Then choose **One PDF per student** and select all six `student_0X_*.pdf` files at once.

**Combined:** choose **One combined PDF**, upload `combined_all_students.pdf` and set **Pages per student** to `2`.
